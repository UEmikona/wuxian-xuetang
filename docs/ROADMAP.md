# 路线图

本路线图反映规划方向，优先级可能根据反馈调整。欢迎在 Issues 中投票。

## 已完成

- [x] **1.0.0** 本地账号、课程列表与播放、断点续播、进度、笔记、成就、后台播放、深色模式、学习统计
- [x] **1.1.0** 更名"无限学堂"；占位课程与视频；底部导航；分类、搜索；收藏、购买（占位）；学习页；占位页
- [x] **1.2.0** 全屏、进度拖动、倍速、双击快进、控件自动隐藏、自动播放下一课、课时列表、定时关闭

## 近期计划

- [ ] 真实封面图片加载（引入图片加载库与缓存）
- [ ] 字幕开关与字幕文件（WebVTT / SRT）支持
- [ ] 画质选择（HLS 多码率）
- [ ] 音量与亮度手势（左右滑动调节）
- [ ] 播放器中直接添加笔记时的时间戳预览
- [ ] Room 数据库正式迁移（Migration）与迁移测试

## 中期计划

- [ ] 离线下载课时（带存储空间管理）
- [ ] 学习计划与每日目标提醒
- [ ] 课程问答（本地草稿与占位 API）
- [ ] 仪器测试：Compose UI Test 覆盖播放页与购买流程
- [ ] 本地化：英文界面

## 长期设想

- [ ] 云端账号与学习数据同步（需设计隐私与数据删除方案）
- [ ] 真实支付接入（需单独的安全与合规评审）
- [ ] 实时互动：弹幕、聊天、同步播放

## 明确不做（当前阶段）

- 不内置任何受版权保护的课程内容或视频。
- 不在没有安全评审的情况下接入支付或收集个人信息。
